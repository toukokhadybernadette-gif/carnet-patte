Récupérer vos données

Vos animaux, soins, pesées, documents et fiches de garde sont enregistrés sur cet appareil, pour cette adresse. Rien n'est envoyé sur internet : il faut les exporter ici, puis les importer là-bas.

  1. Exporter ici. Touchez « Télécharger ma sauvegarde » (ou, dans l'appli : Profil → Sauvegarde → Télécharger).

    Calcul de la taille de votre sauvegarde…

  2. Ouvrir la nouvelle adresse dans Safari (bouton ci-dessus).
  3. Importer là-bas. Dans la nouvelle appli : Profil → Sauvegarde → « Choisir un fichier… », puis choisissez le fichier téléchargé (nommé carnet-patte-AAAA-MM-JJ.json, dans Fichiers → Téléchargements) et confirmez.
  4. Réinstaller l'appli. Dans Safari, sur la nouvelle adresse : Partager → « Sur l'écran d'accueil ». Une fois vos données retrouvées, vous pouvez supprimer l'ancienne icône.

Vous utilisez Carnet Patte sur plusieurs appareils ? Faites ces étapes sur chacun : les données de l'un ne sont pas celles de l'autre. Aucune donnée n'est envoyée à l'éditeur du site.
